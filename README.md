# Web Search Menu

Search the web for selected text or the note title from the right-click menu, with engines you define.

## Usage

Select some text and right-click: the menu gets **Search Google for “your words”** and a second engine, plus **Search the web with...** to pick any other engine from your list. Right-click a note in the file explorer, or a tab, to search for its title.

Commands (all on the command palette, so you can give them hotkeys):

- **Search the web for the selection**, and **...with...** to choose the engine.
- **Search the web for the note title**, and **...with...** to choose the engine.

Selected Markdown is cleaned first: `[[Note|alias]]` searches for `alias`, links, bold, highlights and list markers are dropped. In reading view there is no right-click item; use the commands, which search the text you selected there.

Built-in engines: Google, DuckDuckGo, Wikipedia, YouTube, Google Scholar, Bing. Add your own in the settings, one per line, with `{query}` where the search text goes:

```
Kagi | https://kagi.com/search?q={query}
Maps | https://www.google.com/maps/search/{query}
GitHub | https://github.com/search?q={query}
```

The first engine in the list is the default. Settings also choose how many engines get their own menu item.

## Privacy

The plugin sends nothing anywhere itself. It opens the search address in your browser, so the search engine you pick sees the text you searched for.

## Installation

In Obsidian, open **Settings → Community plugins → Browse** and search for "Web Search Menu".
